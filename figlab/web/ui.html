figlab 操作说明

三种鼠标模式（图层 / 拖点 / 移线 / 选线 / 框选）互斥：开一个会自动关掉另一个，不会抢鼠标。

鼠标模式

按钮作用
✎ 图层直接拖动图上标注、双击改文字、右侧面板增删标注
拖点按住数据点拖动改数值（改 X / Y / XY 可选），松手写回并重导出核验
⇄ 移线按住任意曲线拖动 = 整条平移，只改显示位置，数据不动
◎ 选线鼠标扫过哪条线就高亮哪条，单击即选中；选中后右上角可「只看这条 / 删点 / 表」
▭ 框选删点拉框选中框内点，再「不画」或「删行」；配合选线可只框一条线
连线散点 / 折线 / 平滑三种画法循环切换，数据不动

快捷键

键作用
Esc逐层退出：清框选的点 → 退出当前模式 → 取消选中 → 关帮助
?打开 / 关闭本说明
Delete / ⏎把框选的点「不画」（数据保留，曲线断开）
Shift+Delete把框选的行从工作副本里彻底删除
Ctrl+Z / Ctrl+Y撤销 / 重做
Shift+拖动不开框选模式也能临时拉框
滚轮 / 拖动 / 双击缩放 / 平移 / 复位视图

导出与项目

入口说明

保存项目 / 打开项目.figlab 单文件；打开恢复为新图，原文件不动
自动导出停手 1.2 秒后台自动导出核验，只写 outputs\，不进桌面
